# Engineering & SDLC Pillars (`agy-dev-plugin`)

All software development, scripting, automation, and repository configuration changes MUST follow these foundational engineering standards:

## 1. Foundational Architecture & Portability
1. **Unix Portability (`macOS` & `Linux`)**: Prefer Python standard library (`pathlib`, `shutil`, `sqlite3`, `fcntl`, `urllib.request`) and POSIX `/usr/bin/*` utilities. Gate any optional macOS integration (`open`, `pbcopy`, `UseKeychain`) behind runtime OS checks (`platform.system() == "Darwin"`).
2. **Primary Languages (`Python 3`, `POSIX / Bash Shell`, `Vanilla Web: JS / HTML5 / CSS3`)**: Implement backend logic, APIs, CLI tools, static auditors, and tests in Python 3 (`pyproject.toml`), installers/wrappers in POSIX Shell / Bash (`bash -n`, `zsh -n`, `bats`), and web UIs **Vanilla-First & Zero-Build** (`ES2022+` JavaScript, semantic `HTML5`, `CSS3` with custom-property design tokens — 100% Santa Lockdown safe without `npm`/`node` bundlers). Node/TypeScript/frameworks are permitted only when explicitly declared by a target repository.
3. **Santa Lockdown Compliance (Binary Download & Execution Safety)**: Corporate workstations run Google Santa in Lockdown mode, which blocks unapproved standalone compiled binaries (`Mach-O` / `ELF`). Never pipe remote scripts to shells or interpreters (`curl|sh`, `wget|sh`, `curl|python*`), never download executable binaries from GitHub Releases (`releases/download` + `chmod +x`), never invoke unapproved binary managers (`mise`, `uv tool install`, `deno`, `bun`, `cargo binstall`), and avoid Python/Node packages or `pre-commit` hooks (`language: rust|golang|node|conda|docker`) that fetch unsigned native binaries locally (e.g., `esbuild`, `swc`, `biome`, `sass-embedded`, `ruff`/`uv`/`playwright` standalone CLIs). Rely on pure-script runtimes (`asdf` via `.tool-versions` + `.tool-plugins`, `bats`), Python stdlib and pure-Python wheels (`py3-none-any` in `pyproject.toml`), and OS-signed or corporate-approved utilities (`/usr/bin/git`, `/usr/bin/ssh`, `/usr/bin/curl`, `/usr/bin/sqlite3`, `jq system`). Separate Santa-constrained local scripts (`install.sh`, `Makefile`, local hooks) from ephemeral Linux CI (`ubuntu-24.04`).
4. **Antigravity-Native First & Don't Reinvent the Wheel (Allowed Non-Binary Libraries)**: Whenever new features or changes are proposed, before writing custom implementations, proactively check and adopt existing solutions in strict priority order: (a) **Antigravity-native customizations** (official plugins such as `chrome-devtools-plugin` and `coderabbit`, MCP servers, built-in skills, rules, hooks using the `agy-dev-sdlc-guardrail` flat schema, dedicated agents, and Agent Marketplace), (b) **standard library & platform built-ins** (Python 3 stdlib, native Browser/Web Platform APIs, POSIX utilities), and (c) **allowed non-binary libraries** (Santa Lockdown safe — well-maintained pure-Python `py3-none-any.whl` packages declared in `pyproject.toml`, or audited zero-build pure-JS/CSS modules vendored locally or SRI-pinned; **never** unapproved standalone compiled binaries or native binary bundlers). If an allowed non-binary library already solves the need cleanly, include and use it rather than reinventing the wheel. Keep plugin definitions, agent personas, rule files, and `SKILL.md` files strictly under `24,000` bytes.
5. **Modular Functional & Data-Driven Engineering**: Favor small, single-purpose pure functions, typed dataclasses / Pydantic schemas, and cohesive modules across Python, Shell, and Vanilla JS/HTML/CSS over ceremonial wrapper hierarchies or monolithic God files. Never duplicate logic; extract shared helpers cleanly.

## 2. Co-Design, Security, Privacy & Manual Gates
6. **Phase 0 Interactive Co-Design (`Grill-Me` by Default)**: `agy-dev-plugin` governs the full SDLC from problem framing to PR merge (`Co-Design -> Planning -> Queue -> Execution -> Maker-Checker Review -> Manual PR`). For any interactive new feature, UX/design change, refactor, open-ended engineering problem, or bug investigation / discrepancy RCA that uncovers `>=2` product, UX, or scope forks (skipping single-cause trivial deterministic fixes, explicit user bypasses, and autonomous subagents/crons), read and follow [`co-design-and-discovery.md`]($HOME/.gemini/config/plugins/agy-dev-plugin/rules/co-design-and-discovery.md): inspect the codebase, active `dev_pr_locks`, and `dev_queue.json` silently first, challenge premises (Antigravity-native alternatives, MVP/YAGNI, debt), co-design via adaptive iterative/compact `ask_question` rounds (NEVER closing an RCA with trailing plain-text open bullet questions when structured `ask_question` co-design applies), and converge on a concise **Design Contract** before planning, queueing, or coding.
7. **Zero PII & Zero Secrets in Tracked Code**: Never commit customer names, domains, personal emails, tokens, credentials, or local `/Users/<user>/` paths into any tracked repository file. Store sensitive runtime configuration exclusively in `0600` `~/.env` (with mock placeholders mirrored in `.env.example`) and untracked state under `~/.local/share/`.
8. **Deterministic-First Engineering & Deterministic Verification Before Reasoning**: Default every repeatable function, skill helper, validation gate, and scheduled/recurring action to deterministic 0-LLM code (`Python 3` / POSIX) following the 4-Tier Determinism Ladder (`Tier 0 -> Tier 3`) and Deterministic Sandwich pattern in [`deterministic-first-engineering.md`]($HOME/.gemini/config/plugins/agy-dev-plugin/rules/deterministic-first-engineering.md). Never invoke an LLM agent where pure code or a 0-LLM pre-gate suffices; codify repeatable checks into fast CLI validators, pre-commit hooks, static AST audits (`project_audit.py` / `qa_static_audit.py`), and `PreToolUse`/`SessionStart` hooks.
9. **Protected `main` Branch Workflow**: Never push directly to `main`. Route every tracked code/config change through `git-commit-configuration` and `agy-code-remediation-pr` (`fix/<YYYYMMDD-HHMMSS>-<scope>-<cid8>` under per-repository `dev_pr_locks`) with independent `agy-code-pr-reviewer` (`Model="pro"`) evaluation and human PR approval.
